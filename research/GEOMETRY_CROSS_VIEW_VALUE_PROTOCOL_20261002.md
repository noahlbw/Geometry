## Complete operator

Module1 is unchanged Geometry. Module2 modifies its attention read in both frozen
head blocks. A native512 fine view and enclosing1024->512 context view share the
same weights, text aliases and original Geometry donor path. Fine queries evolve
along the coupled path; context donors evolve along unchanged original Geometry.

For the SAME current fine Query Q, define normalized image-valid geometric
priors G_f and G_c and native per-head likelihood logits L_v=Q K_v^T/sqrt(d).
P_v=softmax(log(G_v)+L_v), logZ_v=logsumexp(log(G_v)+L_v).
The cross-view prior uses raw DINO cosine/.10 and distance sigma128 original
pixels, matching the fine Geometry physical bandwidth. No coarse token is
treated as a subpixel-perfect semantic observation.

alpha=sigmoid(logZ_c-logZ_f); D=alpha*(P_c V_c-P_f V_f).
Read o=o_Geo + m_patch D on patch queries only. Original special attention,
patch mass, projection, LayerScale, residual, MLP and final LN remain active.
The same fine query compares two actual Value reads BEFORE subsequent nonlinear
semantics; the final prediction is one coupled fine descriptor, not output fusion.
Zero/unobserved context gives exact Geometry. A duplicate context view with the
same donor state/prior has D=0 at every block. A common additive Value vector
cancels because both conditional rows sum to one. These are operator properties,
not calibrated correctness guarantees. Signed displacement can create negative
effective fine donor coefficients; do not claim it is a nonnegative replacement.

Native QK, cross-attention, geometric priors and differential readouts have clear
precedents. The candidate distinguishes matched cross-view Value changes from
old coarse-relation-only rewriting, native-role/profile constraints and post-head
VIP/Geometry score differences. No verified priority gap is claimed. Raw geometry
may be semantically mixed, native QK may favor scene context, and coarse Values
may retain mixture; these are risks to falsify, not assumptions of success.
