# Geometry 主线：竞争式语义重读候选

## 保留的主线与判断依据

保留 `DINOtool/dinotool/gear_ov.py` 中不启用 reconstruction 的 Geometry / Multiscale 路径，以及 `research/gear_ov_v2_*_full_20260929_results.json` 八集结果。当前六集复现了其控制。源码、词表、权重及历史结果不覆盖；新候选不替代强基线。OEM 上 GEAR_OV 的历史增益作为单独证据保留，不据此按数据集切换方法。

区域核验首版完整 VDD 为 41.6176、Potsdam 为 39.4564；Multiscale 为 41.2235 / 40.4433。首版六集两升四降，不能据此认定它是最终模型。

完整上游配置 VIP 官方短词加阈值为 VDD 52.0647 / Potsdam 44.0643；VIP all20 无阈值为 51.0697 / 42.3519。受控实验显示宽物理视野、proxy 视觉头、文本表示与聚合有交互。VDD 的 ImageNet 文本使 VIP 从 47.8037 到 51.0697，却使同配置 Geometry 从 42.7055 到 41.7415。不同因素不能加和，也不能靠固定全局筛词假定填平差距。

## 两个逻辑模块

1. Geometry：保留稠密局部读出、raw DINO 空间关系、逐 alias 响应与现有强 Multiscale 控制。
2. 竞争式语义重读：将 alias 核验和宽视野语义迁移合成同一算子。筛词不是独立全局列表；同一核验状态控制局部 alias 的正向证据和该 alias 上下文的发送/接收。

冻结共享 DINOv3 / DINO.text。局部 Geometry 分支保留细节；宽视野支路采用已复现 VIP 的 proxy 稠密读出与 ImageNet 模板，作为明确归属于 VIP 的语义证据来源，不称为本方法的新视觉头。完整图像长边 448 的宽视野和现有局部视图是候选起点，所有数据集使用相同规则；宽视野不是相同分辨率下随意增加一个 crop。RS / ImageNet 文本各服务于已经匹配的分支，不盲目全局换模板。

该设计的激进之处是取得额外的稠密语义读出，允许可靠语义观测真正改变竞争结果，而非仅将 Geometry 分数削小。它不是单独全局 CLS 分类器，也不是把 VIP 概率图平滑后覆盖局部输出。

## 核验单位与三态证据

单位为 `(alias 的实际视觉支持区域, 父类 c, 当前竞争类 d)`。支持区域由 Geometry 原始特征关系和 alias 实际响应共同定义，不使用四个固定象限，不要求区域只有一个类别，不为缺乏证据的每类强制构造 top25% 原型。

针对支持区域，获取对齐的宽视野稠密语义观察；在必要的分歧支持区域获取真实紧裁剪的语义观察，不能把同一整图向量广播为区域验证。按公开类别定义区分 part / object：VDD 的 wall 与 roof 分开；Potsdam 的 building 可以包含 roof。不能把某个字符串全局标为有害。

核验时从父类及竞争类参考中留出被审查的语义 family。比较父类/竞争类 margin，并计算待抑制 alias 对当前 Geometry 竞争 margin 的实际增量；低激活与有害增量不能混为一谈。留词组与不同视图仍来自同一冻结编码器，不称为统计独立真值。

得到三个证据质量：支持父类 q+、支持竞争类 q-、未解决 q?。它们是待检验的证据量，不先验声称为校准概率。两种操作分别为：

- q- 控制抑制；只有明确竞争类证据才削减该区域里 alias 的正向超额激活。
- q+ 控制迁移；只有明确父类支持才允许该 alias 的语义源与目的位置参与重读。
- q? 保留局部 alias，但不授予上下文修正权。保留不等于可信，这是单一 retention 权重无法表达的区别。

候选最小决策可使用 tight / wide 的留 family 父类-竞争类 margin：同向的正 margin 支持 q+，同向负 margin 支持 q-，反向或缺乏支持归入 q?。连续证据强度替代固定保留 K 或 all-view probability>=0.75。具体尺度必须作为统一配置预声明，不按目标标签调节。

## 耦合算子与退化行为

记局部 Geometry alias cosine 分数为 lG、同词组留出参考为 lref。抑制只影响正向超额：

`l_screen = lG - q_minus * max(lG - lref, 0)`。

弱词不会因删除改变分母而反向增加 car 分数。聚合始终保留原始 20 个 slot 的分母；不对保留下来的权重重新做类内 softmax。

通过 raw DINO 外观、坐标映射和真实区域支持建立跨视图 Geometry transport T。发送侧的 q+ 限制哪些 alias 证据能被搬运，接收侧的 q+ 限制可写入位置；没有可信源时不产生残差。T 不跨明确结构边界广播类别常数，不把任意视觉相似当作语义正确。

候选 alias 更新为：

`l_star = l_screen + q_plus_destination * (l_semantic_transport - l_screen)`。

语义传递既能提高缺失的 water 证据，也能降低局部过强证据；不再只做正向 union。可靠差异不受与当前 gap 绑定的微小固定 clip，但可靠度仍限定插值范围。迁移分数使用统一的归一化 cosine / 温度约定；VIP 的 40 倍 logits 与 Geometry cosine 不直接相加。VIP salience 先作为 source 选择参照，不把未经匹配验证的 logits 缩放照搬成最终混合权重。

对每个现有 Geometry 视图执行同一算子并重新聚合 alias。保持强基线完全一致的输出构成为：

`Z_final = Z_Multiscale + mean_v(LME(l_star_v) - LME(lG_v))`。

所有区域未知或没有可信迁移源、且没有明确冲突时，修正严格为零，输出退化到原始 Multiscale，而不是另一种 alias-average 基线。主要头只重读一次；不引入新的网络训练 loss、反复潜变量优化或事后按类别选分支。

## 闭环与创新边界

Geometry 定义实际支持区域与迁移路径；alias 竞争核验提供三态状态；同一状态同时改变局部 alias 贡献、语义源和写回位置；重新聚合后的证据决定最终竞争结果。筛词是这个重读算子的证据控制，不是第三个插件。

单纯 VIP+Geometry 集成、ImageNet 模板、多尺度、soft gate、固定分母都不单独作为新贡献。可检验的贡献只能是：基于实际支持区域的竞争式证据决策，是否比简单集成更好地保留正确覆盖、减少竞争类误激活，并让 Geometry 的空间读出获得可靠的宽视野语义。

若最终只是平滑 VIP 且不能胜过同等输入/计算预算的简单组合，应如实降低创新与性能判断，不能依靠命名解决。

## 后续唯一建议的验证顺序（本次不启动）

先在 VDD / Potsdam 的既有开发协议比较 Multiscale、同词表 VIP、简单固定融合、上述联合重读。消融必须区分只筛词、无筛词迁移、耦合重读；保留官方短词 VIP 作为另一原生协议参考。使用全分辨率指标、逐类 TP/FP/FN 与有益/有害改动，不能从 sampled LOO 指标推断全量收益。

预声明机制闸门：联合重读在两个开发集都优于 Multiscale，并超过简单融合；水体召回 / car precision 的改善不能以任意牺牲其它类掩盖。若过闸，再固定一次规则向其它数据集迁移，统计平均收益与退化数据集，而非按集挑配置。这些已反复使用的数据集是开发/探索性验证，论文需补独立区域或新划分验证。

当前不承诺超过 VIP，也不将已有强分数等同于 CVPR 可接收性。设计比首版更直接针对已证实缺口；能否成立取决于新的稠密语义证据与竞争决策是否真的优于简单参照。
