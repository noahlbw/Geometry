## Two-Mechanism Complete Architecture

```text
image + class ontology + candidate aliases
                     |
              frozen image/text encoders
                     |
       +-------------+---------------------------+
       |                                         |
1. Geometry local reader                 contextual observations
native local descriptors Yg              original attributed wide observer
class anchor g, relation G               broad field b and alias evidence r
       |                                 optional native fine witness f
       +------------------+----------------------+
                          |
2. query/rival-conditioned contextual admission and reconstruction
      continuous alias contribution control, unknown retains evidence
      same-path aggregation -> coherent admitted class field b*
      Geometry-anchored writeback, preserving the original local anchor
                          |
                unchanged dense assembly/prediction
```

Mechanism1 remains frozen: preserve native mass allocation, special-token
contribution, both frozen head blocks, residual/MLP/normalization, templates
and normalized local LME. Its output is local evidence plus a visual relation,
not a semantic correctness oracle.

Mechanism2 is one coupled evidence reader, not a global vocabulary filter plus
several unrelated gates. The wide observer, encoders, templates and classical
solvers are attributed components. A word can be retained against C while
attenuated against B at the same query. Local20 stays unchanged until a
separate matched study supports changing it.

The retained deployed model has no promoted alias controller: b*=b. The tested
research extension measures actual broad/native alias-versus-rival margins and
uses gamma(i,a,d) in [0,1]. Native-query-only risk is nonzero only for broad
margin >0 and native margin <0. Canonical/self/invalid actions remain zero;
unknown means retained, not confidently correct. This detects cross-view
disagreement, not all wrong words or shared encoder errors.

Within the original profiled observer, q=softmax(beta*r). These dynamic alias
responsibilities already describe response influence, not word reliability.
The tested excess-suppression writer is:

```text
d(c|d) = log(1 - sum_a gamma(c,a,d)*max(q_a-1/K,0))/beta
e(c,d) = d(c|d) - d(d|c)
v_c = mean_d e(c,d)
b* = b + v
```

Its consistency projection is classical least squares. Final reconstruction is
the retained inference objective, not a supervised training loss:

```text
min_z 0.5*||z-g||_F^2 + 0.5*||G(z-b*)||_F^2
H_G = (I + G^T G)^(-1) G^T G
z = g + H_G(b*-g)
```

Zero risk recovers original coupling; b*=g recovers the local anchor. These
identities do not guarantee preservation of small objects: H_G can have signed
entries and semantic evidence can remain wrong. Positive relative v is not a
certificate that a good alias was discovered or positively rewarded.

## The Next Necessary Candidate, Not A Promoted Final Model

Do not add another encoder, stronger Geometry veto, learned calibration or
phrase blacklist. The next focused question is whether the current suppression
writer loses useful relative evidence because it controls only above-uniform
responsibility. Hard/soft currently differ in both strength and normalization.
It would be incorrect to diagnose the entire gap as a weak gamma.

Plan a prospective SAME-SOURCE soft-survival aggregation:

```text
w_a = 1 - gamma(i,a,d)
s_w(c|d) = log(sum_a w_a*exp(beta*r_a)/sum_a w_a)/beta
delta(c|d) = [log(1-sum_a gamma_a*q_a)
              - log(1-mean_a gamma_a)]/beta
```

Apply this inside each original crop before its exact stencil/overlap, retain
all rivals, and use the same classical coherent field and anchored writer.
`s_w` names the normalized component; the original VIP scorer uses unnormalized
LSE. Keep its inherited `log(K)/beta` offset and apply only the displayed delta
to the original score, so zero-risk numerical replay is preserved.
No new salience recalculation, source, TopK or label-selected gain. Zero risk
is identity; binary risk reproduces the current hard survivor-normalized
aggregation; constant within-class risk leaves its normalized score unchanged.
Canonical protection keeps the denominator nonzero in this existing contract.
It can yield signed class changes, so it does NOT obey the current soft
suppression-only cap. That change must be explicit and tested, not hidden.

This is a different source/writer combination from the Oct2 soft-counterfactual
experiment, which used leave-out pseudo-label donors, half-uniform utility
weights and a bounded top2 partition update. It is also not a new invention
merely because weighted LME is rewritten: survivor normalization is standard.
Its purpose is to isolate the unresolved aggregation question before making
a second-contribution claim. Do not present it as already improving mIoU.

Freeze equations, controls and a new gate BEFORE predictions. Compare current
excess-soft, normalized-soft and hard with the same native risk, plus matching
text-only, risk permutations and signed-action budget controls. Judge clean and
legitimate paraphrase safety AND actually harmful vocabulary regimes, not only
mean improvement over hard deletion. Do not adopt a control or select a strength
from this screen. Any subsequent evaluation is a new development study.

Before a paper-model promotion, require complete-image evidence on fixed IDs,
a reproducible genuine raw-LLM bank and a held-out vocabulary/region after
freezing. Pure-addition and replacement stress answer different questions; word
count/normalization and source cost must be matched. If actual placement still
cannot beat text-only/permuted controls, remove the unsupported visual alias
reliability claim instead of attaching a third module. The fallback paper is
Geometry with an explicitly attributed coupled observer and defensible
nearest-method distinction, not a fabricated successful selector.

Only a mechanism that passes those checks proceeds to full eight-domain
validation. Report official VIP under its released protocol and matched20 VIP
separately, independent predictor cost, foreground metrics, per-class
precision/recall/area and size/boundary errors. General OVSS claims additionally
need natural-image evaluation with matched general templates. Current screens
do not establish all-eight superiority or CVPR acceptance.
