# CVPR 最终模型：设计目标、alias 决策与停止条件

日期：2026-10-09。本文保留最初设计及停止条件；后续已进入冻结执行，见 `CVPR_FINALIZATION_EXECUTION_20261009.md` 和 `ALIAS_FINALIZATION_20261009.md`。规划不是验证结论，当前最终模型 goal 仍活跃。

## 1. 决策

保留 Geometry、宽视野观测和 Geometry 支持的耦合写回作为母模型。条件化 alias 使用属于耦合读出内部的证据决策，不预先要求它成为第三个独立创新模块。

目前没有同时通过低成本、跨域增益和词级机制归因的最终筛词器。下一阶段的目标是完成这个问题的科学定案，而不是持续试权重直到找到正数。允许两种结局：

1. 找到具有实质精度或词表稳健性收益的低成本处理，纳入最终模型；按实际证据陈述其作用。
2. 有界探索后仍不成立，冻结更简洁的 Geometry＋耦合模型，保留可审计的词表输入协议，撤回“能够识别像素级坏词”的主张。此时还需独立判断 Geometry 和耦合本身的贡献是否足够；不能据此保证 CVPR 录用。

八域全部胜过 VIP 是性能愿望，不是一个能够保证达成的研究完成条件。单域最佳历史结果拼成的模型也不是统一终版。

最新语义约束中，Potsdam 新增正确 20,362 像素，同时新增错误 20,614 像素；ADE 新增正确 239,063，新增错误 416,006。模块不是完全不触发，而是尚不能稳定辨别正确抑制与错误抑制。ADE mIoU 小幅上升与总正确像素下降并不矛盾，两者度量不同。

最新四域结果使用同轮冻结缓存做有效配对。ADE 对更早历史基线存在 CPU/GPU 文本归一化造成的微小重放差异，不能写成历史逐图精确一致；详见原报告。VOC20 忽略背景，不代表 VOC21。

## 3. 需要修正的两个前提

### 3.1 现有模型并非把所有词的实际贡献一律等权

局部使用 log-mean-exp。令局部 alias 响应为 s，词数为 K：

    L_c = t * log(sum_a exp(s_ca/t) / K_c)

它对单个响应的导数是 softmax(s/t)，高响应词实际具有更大的影响。宽视野还继承图像条件 salience：

    q_ca = softmax_a(global_similarity_ca / tem)
    e_pca = K_c * q_ca * alias_logit_pca
    W_pc = log(sum_a exp(tau * e_pca)) / tau

因此“没有新增筛词器”不等于“完全没有动态词贡献”。真正没有证明的是：当前动态贡献能否反映特定竞争中的判别可靠性。再添加一个非均匀 softmax 本身不解决这个问题，也不自然构成创新。

### 3.2 所有 alias 最后都经过类别聚合这个接口

现有写回为：

    Z = L + g H (W - L)

固定 H 和 g 后，修改局部与宽视野分数的结果满足：

    delta Z = (I - gH) delta L + gH delta W

下游不再直接看词身份。若两个规则产生完全相同的 delta L、delta W，它们必然产生相同 Z。这不是需要重跑的消融。

逐词处理的价值只能体现为：在不看标签时，它比类别级规则更能算出有用的修正场。不能把“同位置、同类别、同精确修正场”的类别控制拿来要求额外词级收益；那是代数上不可能的。有效的类别对照应具有相同输入信息和相近预算，但独立计算修正，而非复制主方法完整输出。

H 可能具有负元素，既非语义真值，也非非负概率传输。某处压低 W 不保证所有输出位置同类分数都下降。必须评估最终竞争边界、TP/FP 和完整预测，不能只看 alias 的响应下降。

## 4. 筛选、降权、可变词表各自负责什么

| 操作 | 推荐用途 | 不应声称 |
| --- | --- | --- |
| 硬筛选 | 离线清除明显格式重复、与公开标签定义明确冲突的归属；不按视觉低响应机械删除 | 自动语言审核等于语义真值；一次删除适用于所有位置 |
| 在线软降权 | 仅在可用证据支持的局部竞争中限制贡献；无法判断时保持原模型 | 不同权重天然等于发现了好词、坏词 |
| 可变词表 | 允许每类有效表达数不同，检验生成协议、冗余和错误输入的稳健性 | Qwen 输出多少就天然最优；词数本身代表类别先验 |
| 类别校准 | 单独控制类别分数尺度、背景/残余类和聚合质量 | 把纯类别偏移的收益归到 alias 选择 |

明确的其他类名称也须按任务标签定义判断。比如“truck 是否属于 vehicle/car”取决于标注本体；“roof 属于 building”可以成立，不能仅因它不是类名同义词就删掉。背景/other 常是不同概念的并集，不能与前景同义词池使用未经验证的统一计数法。

建议主模型开发阶段固定当前同输入词池，以隔离处理作用。词表可变能力放到机制冻结后验证。若最终使用 Qwen，公开类别定义输入、提示词、模型版本、采样设置、原始候选、处理记录和最终词表；生成时不输入目标图像标签或按评测分数反复选词。

## 5. 下一步主线：以最终竞争动作作为降权的预测目标

首选研究路线仍是稀疏、条件化的软准入；硬删除只作为其极端动作和离线输入治理。这里确定的是问题接口，不是已经发现一个有效的新权重公式。

对原预测冻结的竞争对 (c,r)、Geometry 支持位置 S 和候选 alias a，定义动作：仅在 S 内衰减 a 对 c 的贡献，并通过原写回得到完整预测。该动作的研究效用是它对最终正确覆盖、竞争误激活和 mIoU 的影响，不是它与 canonical、邻居或者另一分支有多相似。

可以保持如下最小实现约束：

    rho(p,c,a | r) in [0,1]
    rho(canonical) = 1
    未识别/不支持的竞争 -> rho = 1
    W'_pc = log(sum_a rho(p,c,a|r) * exp(tau*e_pca)) / tau
    Z' = L + g H (W' - L)

公式沿用原宽视野 salience、槽位与聚合约定。rho 全为 1 时恢复母模型；降低 rho 不重新放大幸存词。最初只改一条语义通路，避免同时改变局部锚点、宽视野校准和写回，导致收益无法归因。若后续改变局部，必须显式计入 (I-gH)delta L。

这个固定槽位写法及 canonical 保护都属于已经探索过的机制，不能再作为新贡献；canonical 也不是真值。真正待解决的是 rho 所依赖的证据。当前没有一个已通过证据检验的估计器，因而不能诚实地宣称下一次换 sigmoid、top-k 或强度就会成功。

新候选开始前必须写清三点：它读取了哪种现有失败方法未充分利用的信息，为什么能区分误激活与正确覆盖，以及这种信息如何影响最终写回。可以来自同一冻结模型中的不同可用信息，不要求必然增加编码器；但“同源信号更加一致”不是额外语义正确性的证明。

已完成的有界动作审计证明一些标签辅助抑制动作有收益，不能重复投入去证明“抑制存在空间”。旧审计的词级整图删除与未来局部条件动作不同；只有动作定义确实变化时，才补一个针对性诊断。标签仅测量冻结动作的后果，不能用于拟合上线 rho，也不能把标签辅助结果写成 training-free 性能。

如果无法提出实质不同、可检验的证据来源，直接进入终版取舍，不启动又一轮完整评测。不是证明研究方向不可能，而是避免在没有新假设时延长同一个搜索。

## 6. 最小实验与执行阶段

### 阶段 A：冻结母模型与评测口径

选定一个代码实现和确定的配置表，保留历史最佳快照。明确 Geometry 是原始条件质量保持版本还是 PatchOnly2；两者不共享所有理论性质。冻结宽视野来源、窗口数上限、模板、词表、背景协议、数值修复和读出参数。

已有按数据集开发的参数可以如实公布，但不能在 alias 对照中同时修改。统一方法不要求不同任务必须拥有同一标签表；它要求变化项事先声明，且没有按最终结果选择开关或版本。

已有四域 no-contract 配置不是历史各域最佳配置。后续既需对同母模型开关比较，也需把真正保留的最佳系统作为整体性能参考；不能挑弱母模型制造“新模块涨分”。

### 阶段 B：一个主假设，最多一次有依据的修订

先复用现有开发缓存；只在新信息确有缺口时采集最少必要数据。先测实现的整图成本，再决定是否展开精度实验。

核心对照：

1. B0：同词、同观测、同协议的原耦合。
2. Bc：独立计算的类别级处理，不读取逐 alias 的风险判断；若候选存在解析类别偏移，单独加入该偏移控制。
3. Ba：候选条件化 alias 处理。

不新增大批权重打乱组。Bc 是为了回答当前最关键的校准解释；它不能复制 Ba 完整修正场。若再增加一条观测或语义头，必须把“使用该观测但不筛词”的控制补齐。

最多一个正式候选加一次有明确机制理由的修订；修改强度、名称或随结果换数据集不算一个新假设。已有失败估计器不重新包装。

### 阶段 C：四域验证与冻结

开发域使用 VDD、Potsdam、ADE150、VOC；VOC20 用于衔接既有对照，最终必须加入 VOC21 背景协议。四域均已参与过开发，不能称独立验证。

先报告完整数据集开关增量、类别控制差值、TP/FP/FN、有效词贡献变化与开销。精度取舍不能只看本类：别类降权也会改变本类 IoU。不能由少量挑选可视化取代全量结果。

机制通过后一次冻结，再迁移到其余遥感/自然任务。使用全部已有可用任务的统一清单；未完成数据不填估计数。LoveDA P/D 分列，八域均值只计 D 一次；VOC20/21、PC59/60 分别报告，不借协议切换提升分数。

### 阶段 D：词表稳健性与最终模型审查

冻结候选后，比较原20、可变数量生成词表、重复表达、含糊上位概念、错误归属词和正确新表达。选词规则及污染场景在看结果前确定，不只挑有利错误词。

重复不变性和一般冗余分组已有实现与失败结果，复用它们作对照。至少与“不处理”和“简单去重/公开定义审核”比较。先按预先固定的若干词表实例测机制；如果结果驱动改设计，这批词表同样转为开发材料。

最终主模型不按数据集分别选 Ba/B0；如果只能用域开关避免损失，需承认统一机制未成立。最终独立验证需真正未参与方法/词表选择的新区域、样本源或官方测试条件。旧验证集重分组不能消除长期开发偏倚。

## 7. 建议预先冻结的验收标准

以下是本项目下一阶段建议的工程决策线，不是统计定理、既有实验承诺或 CVPR 录用门槛。正式候选实验前一次冻结，不能根据其结果下调。

| 维度 | 建议标准 |
| --- | --- |
| 增量成本 | alias＋新增语义头的整图增量中位数不超过母模型 20%；同时报告 p95 和最坏尺寸 |
| 整体成本 | 同硬件同输入同计时边界目标约 2–3× VIP；超过 3×须说明收益代价，超过既有 6×上限停止扩展 |
| 计算结构 | 首选零新增视觉前向；固定候选竞争数，例如 top2；无位置×类×alias×全部对手张量 |
| 精度路线 | 四域同输入等域平均至少 +0.2pp，至少 3/4 不退，最差域不低于 −0.3pp；配对区间及类别风险完整报告 |
| 归因 | 相对 Bc 有正的可迁移增量；解析类别偏移不能解释全部收益；不要求数学上不可能的同修正场额外优势 |
| 稳健性路线 | 干净输入平均不低于 −0.1pp、最差域不低于 −0.3pp；预定多种真实扩词/错误输入下的平均退化比 B0 至少减少 25%，并胜过简单审核/去重 |
| 迁移 | 同一处理规则迁移到其余任务，报告全部域；不能按域挑候选；只有新冻结后的数据可支撑独立泛化主张 |

稳健性改善的相对百分比仅在 B0 确实退化且幅度有实际意义时计算；同时给出绝对 pp 和逐场景结果。不能在原下降接近零时用百分比放大微小差异，也不能用污染收益掩盖干净词表大幅退化。两条路线须事先声明，不能精度失败后临时挑一个污染场景转称成功。

基础点积代价约 O(PCKD)，已有 alias 归约 O(PCK)。在线仅处理固定数量竞争者时，额外词操作应控制在 O(PRK) 加必要类分数操作；这里 R 是每个位置总共参与处理的类别/有向竞争数量，例如原预测 top2 的两个方向，不是为每个类别各取 R 个对手。后一种实现仍是 O(PCRK)。top2 从已计算的原类别分数选取，R 固定且不随 C 增长。保留词数的分块实现，避免显式 C²K 中间量。Geometry 现有 P²关系不因此变成线性复杂度。

成本测量使用独立执行的单模型、同一批完整图、预热与 CUDA 同步，包含缩放、所有编码、读出、词处理、写回、原尺寸恢复及预测输出；解码和初始化另报。至少覆盖各域多种长宽比/尺寸，报告实际编码次数、绝对 ms、相对 VIP、峰值 allocated/reserved；现有每域三图计时不能冒称全量平均或独立部署内存。

## 8. CVPR 的贡献结构与必要消融

建议主题保持：“利用视觉结构组织局部读取，并约束竞争性语言证据的修正写回。”

第一部分阐明 Geometry 的实际算子及其与最近方法的具体差异。原始条件质量保持 Geometry 的性质不能移给当前 PatchOnly2；与 Native 大幅差距也不能代替与 SCLIP、VIPProxy 等匹配读出对照。已有近邻对照可以复用，若终版算子或分辨率改了，相关结论需重新匹配。

第二部分阐明同样局部/宽视野观测下，Geometry 支持写回相对直接宽视野、简单融合的独立价值。VIP 宽视野观测继续明确归属，不能因为整体耦合不同就把继承部分写成新视觉编码器。

如果 alias 路线通过，将它写为第二部分中的证据准入：何种竞争修正被允许进入、为什么不永久删词、为什么 Geometry 通路必要。如果仅稳健性通过，只主张词表扰动稳健性；如果仅校准有效，就称校准。三个框并不是三项新贡献。

最小必要消融是：匹配最近读出、Geometry 局部、同源简单融合、Geometry 写回、alias 开关、必要类别偏移控制。还需全图/前景/背景协议、边界/尺度及类别误差分析和完整推理成本。已通过的消融直接引用，不因写论文重复重跑。

最终性能表并列两类比较：作者官方/声明配置的完整 VIP 与同词同观测预算的匹配 VIP。所有 empty-row 数值修复如实报告；历史 NaN 污染的低分不再用作有利基准。论文数字、自己复现的官方配置结果和同20词比较不得混称。

本轮没有开展新的文献检索，因此不声称新的优先权或完整覆盖最新方法；最终定稿仍须做对应算子的近邻文献/源码核查。

## 9. 可直接用于后续实现验证的 goal
