# 自动读出与保守竞争降权：五协议完整结果

## 结论

任务条件化读出已完成 VDD、Potsdam、VOC21、PC60、ADE150 的全量验证。保守竞争降权不需要新增视觉编码，避免了旧 canonical 锚定方案在遥感上的明显退化，但自身增益很小，暂不足以作为主要性能贡献。

没有修改保留的原最佳模型或历史输出。两套完整队列均正常结束，无失败任务；各覆盖 9138 个协议图像。收集器验证唯一完整覆盖、逐图混淆矩阵求和、固定权重及原 Reference 重放；新保守方案的 Reference 和 TaxonomyAdaptive 两个不变分支还与上一队列的混淆矩阵精确一致。

## 自动选择的实际规则

- 自然任务：从类别 canonical 文本的中心化 Gram 有效秩计算语义可分性；rank/C 转为 odds，再在固定 0.5/1/2 菜单中选择耦合增益。选 0.5 时保留 original Geometry，其余使用 patch-only strength2。VOC21 选择2，PC60选择1，ADE150选择0.5。三者共享 segmentation 模板、变长语义候选池、温度0.07，无背景拒绝或偏置。
- 遥感任务：使用既有 original Geometry 特征，比较两个冻结文本路线的 canonical top-two margin；不含 residual 类和 padding patch。original20/ImageNet 对应 strength1；focused20/RS6 对应 strength3；二者共享耦合0.5。VDD选择 ImageNet 79/80；Potsdam选择 focused 371/504。
- 此处 strength 是读出算子的读取强度，不是将最终类别 logits 直接乘常数。

这些规则受既有标签开发曲线启发，遥感候选路线也有标签开发来源。在线选择不读掩码，但不能称为 parameter-free 或 untouched independent validation。参数—语义可分性的关系目前是可检验假设，不是已证明规律；不能仅凭类别数量推断细粒度程度。

## 保守竞争降权

先由未筛选的类分数找当前竞争类，再用 alias 相对于本类与竞争类文本质心的相似度差产生归一化权重 q。每个 alias 的最终权重为：

`w = 0.5 / K + 0.5 * q`，其中每类 `sum(w)=1`。

使用 `T * logsumexp(alias_score / T + log(w))` 聚合，T=0.07。每个 alias 至少保留原均匀权重的一半，因此局部原始类分数相对未降权结果的下降不超过 `T*ln(2)`。这个界限不保证耦合后类别胜负、召回或 mIoU。0.5保留比例仍是固定开发假设，不是无参数结论。

## 对最终模型的决定

保留 Geometry + 有界宽视野 + 耦合读出的主体。自动读出是当前可用候选；保守软降权可作为低成本可选机制，但不能为了故事把近零增益包装成主要贡献。旧canonical锚定不适合全域统一采用；置信度混合背景拒绝已失败，不并入终版。

剩余工作首先包括PC60残余类的语义覆盖修复，以及冻结规则后在其他域/协议上的迁移，而不是继续按目标数据集挑权重。对词表数量的自适应也需要候选生成规则与按类归一化，不能把Qwen输出数量或自报信心当作视觉有效性证明。
