## Information Difference

The prior covariance experiment compared each word with canonical CLASS margin
variation. The rival-span experiment projected static TEXT vectors and used
survivor redistribution. This source instead compares original wide WORD
response patterns with the current rival's WORD response patterns in an
image-local Geometry support. No canonical field defines semantic truth.
Pearson correlation, squared explained variation and ridge have precedents;
this is a source/conditional-use test, not a new statistical theorem.

## Frozen Rule

Use unchanged20 words, original templates/checkpoints, bounded896 patch-only2
Geometry, bounded448 VIP wide, original W/H, calibration and restoration.
At most4 local/4 wide actual encodings; NO fine/RGB/head/text extras. Select
the unchanged baseline top2 competitors. Each query uses at most32 original-G
neighbours, excluding self and padding, with normalized positive donor mass.

For word a in class c and word b in current rival r, compute weighted Pearson
rho[a,b] from their donor responses, and original-logit donor means mu[b].

    risk[a|r] = sum_b softmax(mu[r])[b] * max(rho[a,b],0)^2
    weight[a|r] = max(1-risk[a|r],1e-6)

Unknown/constant variation contributes zero risk. Canonical, invalid and equal
class entries retain1. Query response does not enter correlation or rival
responsibility; it still enters the original prediction/action carrier. The
same word can be attenuated for one rival and retained for another. Retain all
prediction slots and original salience, with no survivor mass compensation.
Original H writes the antisymmetric fixed-slot pair potential. There is no
label fitting, target-semantic guarantee or persistent dataset selection.

Co-varying words can describe legitimate context or co-occurring objects.
Unknown constant wrong evidence survives. Thus response collision is a proposed
measure of nonexclusive evidence, NOT a correctness probability or bad-word
label. A word with a preserved distinct pattern need not be semantically right.
