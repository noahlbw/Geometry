Freeze Geometry, finite VIP wide readout, original fine views,20 aliases, original
contradiction rule and reconstruction. Same developed64 windows, not independent
or full-dataset evaluation. No new visual forward or fitted parameter.

The preceding attribution controls support alias identity, location and rival
specificity. Direct fine class reconstruction has a higher development mean but
large VDD/LoveDA P losses. Test admitting fine class evidence only where actual
wide alias evidence is contradicted, without deleting words from the input pool.

P_qcd is the original crop/stencil-weighted logsumexp responsibility mass carried
by risk-positive aliases of class c against rival d. It is bounded0..1 and protects
canonical/self/invalid decisions. It is an evidence fraction, not a calibrated
probability of class correctness. High-influence rejected aliases admit more fine
innovation than low-response aliases with the same deletion count.

Let delta=F-B, p=softmax(unchanged coupled scores), v=delta-sum_c p_c*delta_c.
Primary DirectedMassFine_Exact: D_cd=P_cd*v_c, E=D-D^T. Use unchanged posterior
pair reconciliation u_c=sum_d p_d*E_cd with zero gauge and output Z0+H*u.
Zero mass restores Z0 exactly; unit mass recovers full fine reconstruction up to
class gauge. Posterior centering prevents a common view-score offset becoming
a class correction. Individual aliases remain in fine/wide class evidence; this
is soft admission of innovation, not a new normalized per-alias1-risk writer.

Alternatives: PairMassFine_Exact uses max(P_cd,P_dc)*(delta_c-delta_d);

No threshold, strength sweep or dataset switching. Preserve all three outcomes.
