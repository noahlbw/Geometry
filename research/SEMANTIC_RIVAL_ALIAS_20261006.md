Geometry/NoAdmission/PatchOnly2 and previous positive-mean/soft/hard per-image
confusions replay exactly against the preceding local-path study. All scored
targets, checkpoint/vocabulary identities, independent aggregate mIoU and
source/action invariants verify. Original20 aliases/class remain unchanged;
retained_count_mean counts fully unattenuated slots per comparison, not soft
mass or permanent deletion. 17 new tests and26 source regressions pass remotely
with real dependencies. Both mask-free real-checkpoint smokes pass with frozen
weights, exact old six endpoints, singleton equality and actual forward caps.
Every worker exits normally; the original local anchor and source models remain
unchanged. Paired statistics reuse the previously tested offline engine.

These2000 paired filename-source-group intervals are conditional development
evidence, not independent or adjusted for repeated method selection. Identity
nulls average model scores on the SAME resample, not confusion matrices. Risk
identity nulls test assigning weights to the particular source alias; key nulls
test assigning rival-reference mass to the semantically matched rival word.
The first is supported here; the SECOND is not verified. Their distinction is
essential: a0.4106pp no-attenuation gain does not establish usefulness of the
new semantic matching matrix. MatchedPrevious also rules out attributing a
reliable direction benefit beyond the old reference at the same strength.

H correspondence helps7/8 main domains, LandCover.ai excepted; it changes no
positive observation in this control. This supports existing structured writing
relative to correspondence destruction, not a new writer theorem. DirectMatched
is only0.0335pp lower with an interval spanning zero, so new superiority over
matched unstructured writing is unproven in this pilot.

Mean text-reference row entropies are2.7281-2.8654 nats versus log20=2.9957 for
uniform references. Under the evaluator's domain/protocol averaging, changed
positive-risk support spans1.29-2.58% of valid alias/rival comparisons. These
are neither changed native-pixel fractions nor error rates. Matching scales for
the old write span0.9716-1.0249, with zero unmatchable fields. The text reference
remains relatively diffuse and the intervention stays close to the old rule.
These diagnostics DO NOT prove that sharpening the text temperature would help;
no source/temperature is changed after these labels. Semantic similarity still
cannot certify ownership or resolve shared visual errors.

Preserve the existing full Geometry_PatchOnly2Coupled reference and all outputs.
Reject advancement of this source: no post-result threshold, text temperature,
dataset route, favorable-control promotion, timing, vocabulary stress or full
rollout. Its latency is unmeasured and no older timing is borrowed. The existing
one-sided soft reference remains informative; alias-specific semantic rival
matching is not yet a verified added contribution. The next missing distinction
is useful competitive word evidence versus a changed class/reference statistic,
not another local-anchor path or repeated visual-consistency veto.
