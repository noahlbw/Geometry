# Frozen alias sources, competition-conditioned action

Freeze this protocol before reading outcomes. Original Geometry, all20 aliases, finite
VIP wide observer, fine RGB witnesses, risks, hard deletion/count normalization,
reconstruction and dense protocol are unchanged. No extra backbone forward or parameter
sweep. Fine-risk source and three historical score/prediction endpoints must replay exactly.

This follows the developed64 soft/speed studies; the same64 windows are development,
not independent validation. Do not replace full-dataset evidence by this window panel.

## Candidates

Let E_cd be the antisymmetric class-pair action requested by the existing hard alias
writer. Let Z0 be unchanged unscreened coupled patch logits. All final scores remain
Z0 + H u, using the original Geometry reconstruction H.

1. Primary `FineRivalPosterior_Exact`: p=softmax(Z0), temperature1, and
   u_c=sum_d p_d E_cd, followed by removing the class mean. This is the exact weighted
   least-squares pair solution for edge weights p_c*p_d and a fixed zero-sum gauge.
   It changes which rivals determine a query's action, not the alias risk source.
2. `FineActionProjected_Exact`: use the same fine crop profiles and original stencils
   to obtain fine class scores F. Define target pair innovation
   T_cd=(F_c-B_c)-(F_d-B_d), where B is the unchanged wide readout.
   Project E_cd onto the segment from0 to T_cd. Opposing actions are refused and
   aligned actions cannot exceed that fine pair target. Apply original uniform solver.
3. `FineRivalProjected_Exact`: same projection followed by posterior-weighted solver.

## Diagnostic Controls

- Existing original hard action and unchanged no-admission readout.
- `FineTopTwo_Exact`: only Z0's two leading competitors get the original E pair action.
- `FinePosteriorStrengthMatched_Exact`: retain the original action direction/spatial
  pattern and rescale it by a single window scalar to match the reconstructed
  Frobenius norm of the posterior candidate. Tests mere amplification; no control promotion.
- `FineBudgetOnly_Exact`: retain the original pair action magnitudes but orient them
  solely to the fine class target, clipped to its magnitude. Tests fine class evidence
  without the alias-requested direction; no control promotion.

Eight new unit tests cover weighted normal equations, an independent linear solve,
uniform identity, class permutation, projection direction/bounds, top-two support,
exact source/control replay, zero risk and invalid rows. Check actual checkpoint and
vocabulary identities, score persistence before masks, frozen weights, per-image
confusions, scored target counts and classwise beneficial/harmful changes.

Independent warmed pipeline timing: three synchronized repeats, alternated arms,
same first images, same two resident backbones. Compare candidates against cached
hard in the same process/session; not shared evaluation wall time. Report memory.

Preserve all candidates regardless of result. A candidate can advance to complete-image
evaluation if its eight-domain mean improves on hard and no domain/protocol loses
more than1pp. Candidate selection on these windows is explicitly development selection;
never call a selected alternative a prospectively untouched primary. Prefer accuracy
when speed and effect disagree. If only a strength/fine-only control wins, report that
instead of assigning its gain to a new alias mechanism. No automatic full20k rollout.
