## The Intended Two-Module Model

```text
Image + candidate aliases + public class descriptors
                       |
             Frozen image/text encoders
                       |
       +---------------+---------------------+
       |                                     |
Module 1: Geometry                    Original wide observer
local features Y / logits g           inherited VIP head and views
visual relation G                     fixed original alias fields r
       |                                     |
       +--> target/context support ----------+
                       |
Module 2: Interventional contextual evidence reader (PROPOSED)
target-kept / target-removed measurements at matched coordinates
class-pair contextual dependence -> alias retention rho(i,a,c,d)
unknown or object-supported evidence retained; no forced counts
                       |
              bounded observation b_rho
                       |
       same Geometry-anchored innovation reconstruction
                       |
            original assembly -> prediction
```

The second module changes what contextual evidence enters the EXISTING coupled reconstruction. It is not a dataset-level prompt selector plus a separate fusion gate. Geometry gives support coordinates and the reconstruction relation; it does not supply trusted semantic labels. All20 local aliases remain untouched in this first candidate. Therefore this design does not claim to clean aliases in the local anchor.

## Change The Measurement, Not The Writer

The proposed different source asks: does an alias's response at this location depend on the geometry-supported target content, or mainly on its surrounding context?

For a query, construct a soft support M from original class-agnostic Geometry relations, before inspecting text winners. Compare matched-coordinate frozen observations of:

1. Original crop I.
2. Target-kept crop M*I+(1-M)*F.
3. Target-removed crop (1-M)*I+M*F.

F is a fixed label-free fill. Two predeclared fills and same-area shuffled-support controls must distinguish source behavior from masking artifacts. Preserve the original crop coordinates/resolution/template; do not add zoom gains, a new encoder or changing salience to the primary writer simultaneously. Original profiled salience is fixed for the admitted observation; within-source response contrasts should be measured before salience reweighting.

Let s_a^0, s_a^keep and s_a^remove be raw matched-template query responses. One bounded operational hypothesis is:

```text
context_dependence_a = positive(s_a^0-s_a^keep)
                      / (abs(s_a^0-s_a^keep)+abs(s_a^0-s_a^remove)+epsilon)

rival_support(c,d) = positive(p_keep(d)-p_keep(c))
                    / (p_keep(d)+p_keep(c)+epsilon)

harm_a(c,d) = min_over_predeclared_fills(context_dependence_a * rival_support(c,d))
rho_a = 1-max_over_rivals(harm_a)
```

p_keep is canonical-descriptor competition on the target-kept observation, not an all-alias pseudo-label pool containing the tested word. Compare all declared rivals, not only Geometry's top2. Protect canonical words as in the existing writer. No text-parent cosine prerequisite: a correctly attached vehicle phrase must still be eligible for suppression if its spatial response is context-dependent and another class is supported on the target.

Zero/constant support, missing complementary support, unavailable coordinates or inconsistent intervention evidence must remain unknown, rho1. Object-supported aliases should remain active even when close to another class's words. A shared phrase is not automatically harmful. No fixed TopK, global blacklist, renormalized survivor quota or compensating amplification.

This is an explicit candidate source formula, not a semantic certificate. Geometry supports need not be object masks. Masked inputs are out of distribution; both observations share an encoder and can agree on a wrong class. A car phrase misclassifying the target's own roof appearance may remain object-supported and escape this controller. The source experiment must establish whether enough of the actual actionable errors are context-driven. It must not relabel every object-supported false activation as harmless.

The separate pilot freezes these engineering choices in TARGET_CONTEXT_ALIAS_SOURCE_PROTOCOL_20261003.md. Its support/cost/results are now measured, but a successful complete deployable reader is not established. Dense per-query re-encoding cannot silently be assumed affordable on the full20,092 images.

## Admission And Coupled Inference

Keep original profiled alias logits r, K and temperature beta fixed:

```text
q_a = softmax(beta*r)_a
b_rho = b_original + log(1-sum_a((1-rho_a)*positive(q_a-1/K)))/beta

min_z 0.5*||z-g||^2 + 0.5*||G(z-b_rho)||^2
z = g + (I+G^T G)^(-1)G^T G(b_rho-g)
```

The existing suppression writer never increases that class's pre-reconstruction score, keeps good/unknown contributions and does not amplify survivors. rho1 recovers the original observer exactly. Reconstruction can propagate signed innovations; a donor suppression is not necessarily a suppression at every output because the effective operator can have negative entries. Evaluate actual endpoint predictions and competing classes, not just local response decreases.

No supervised loss or network update. The quadratic expression is a frozen inference objective. The VIP observation and classical solver remain attributed components. The intended new contribution, if validated, is geometry-guided measurement and admission of contextual semantic evidence, not the log-sum-exp or solver alone.

## When This Direction Fails

- No separation beyond matched shuffled allocation: reject this source, not strengthen it from labels.
- Useful vehicle suppression is still risk0, or pavement true coverage is systematically suppressed: the new witness has not fixed the measured failure.
- Benefits disappear under fill/support controls: masking artifacts do not establish semantic grounding.
- Only constructed wrong-parent stress improves: restrict the claim; no arbitrary raw-LLM robustness result.
- Source helps, but Geometry coupling loses to same-source simple fusion: revise the coupling claim rather than rename fusion.
- Per-query re-encoding costs overwhelm accuracy gains: this is not an acceptable final inference design without a separately validated amortization.

If this source fails, retaining honest all-alias aggregation in a well-tested Geometry/coupling paper is preferable to adding a nonfunctional screening module. Screening is a research hypothesis, not a prerequisite imposed by the desired narrative.
