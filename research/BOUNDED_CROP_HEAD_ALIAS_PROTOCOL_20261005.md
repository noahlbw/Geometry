# Frozen Crop-Head Alias Pilot

Objective: optimize Geometry-supported competitive language use and writing,
with accuracy and speed equally important. Keep bounded896 Geometry patch-only2,
bounded448 attributed VIP wide observer, all20 candidates, both text banks,
original undoubled G/H, class calibration and stitching unchanged.

New witness: partition each already encoded32x32 local patch grid into four
16x16 subsets, retaining existing prefix inputs. Run the frozen native semantic
head on these four groups as one batch. Mask invalid patch keys; invalid patch
outputs are zero. No RGB crop/resize/backbone forward is added. This changes
semantic reading context, not physical detail resolution. Backbone/prefix
features still contain global context; it is not an independent teacher.

Profile the witness in the original wide template/logit/salience units. For an
alias/rival pair, retain the existing native_risk rule: a positive broad margin
must be contradicted both by the crop-native query margin and by its original
G-supported margin. Apply w=max(1-risk,1e-6), canonical w1, outside the exponent
in normalized weighted log-mean-exp. A/B weights may differ from A/C weights;
no global quota or permanent word removal. Identity weights exactly recover
the original source. The risk is an untrained inconsistency heuristic, not a
semantic-correctness probability.

Pair corrections use the same classical antisymmetric least-squares potential
and write only through the existing H. Local Geometry logits are not rewritten
by the alias rule. Existing visual relations serve both witness support and
correction transport, without treating their coherence as correctness.

Controls: frozen baseline, same-risk hard admission, class-mean soft weights
preserving class weight sums, alias-identity shuffle preserving weight spectra
and canonical slots, and unscreened mean of the same crop-head/wide observations.
Only the soft primary can pass the gate; do not promote a favorable control.

Before masks: five focused CPU tests; mask-free VDD/Potsdam complete-input
original endpoint and singleton/frozen-weight smoke checks. Then UDD5 full40
and eight evenly spaced complete images/other domain,96 unique images total,
matching the preceding same-field audit. These are developed data, not untouched
validation. Per-image original Geometry, unscreened original and patch-only2
confusions must match previous results exactly. All arms use identical scored
target counts. No labels enter witness construction or weighting.

Serial whole-image singleton timing after evaluations finish: three fixed inputs
per domain, three warmed synchronized repeats, matched baseline/primary/VIP20.
Include all views, weighting, H writing, restoration and argmax. Do not infer
standalone model memory from co-resident allocations.

Frozen pilot advancement requirements: mean gain at least0.1pp, at least5/8
domain wins, no protocol loss greater0.5pp; mean above class-mean and shuffled
weights by at least0.05pp, and above same-source observation mean. Mean paired
latency ratio to baseline at most1.3 and every timing-domain mean at most1000ms.
Both accuracy and cost requirements must pass; no post-result relaxation.
A passing pilot requires vocabulary stress and full-domain validation before
final-model selection; no automatic full launch. A failure is preserved and
does not replace the existing performance reference.
