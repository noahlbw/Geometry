templates, checkpoints, local Geometry, equal positive wide/fine information,
original W/H, fixed20 slots and half-strength word intervention. Actual limits

At each ACTUAL fine contributor, e[c,a] is unchanged profiled log evidence:

    F[c,-a] = logsumexp(e[c,b], b!=a) - log(K-1)
    delta[c,a] = F[c,-a] - F[c]

Keep original salience frozen; no reinterpretation as a full salience-refitted
deletion. ONE identical alias is omitted throughout the interpolation footprint,
then delta is interpolated and added to the original sampled F[c]. Completeness
is checked; incomplete observations vote neutral. Prediction bank stays all20.

For parent c and current rival r:

    P = max(B[c]-B[r],0)
    N[a,r] = max(F[r]-F[c,-a],0)
    risk[a,r] = N/(P+N) if B[c]>B[r] and F[c,-a]<F[r], otherwise0
    weight[a,r] = 1-risk[a,r]

Same fixed-slot outside-exponent attenuation of the wide bank, same signed pair
projection and original H. No survivor mass redistribution or truth gate on G.
Changing rival can change the SAME word's weight. Equal words reduce exactly to
pooled-class risk; an excluded word cannot vote in its own reference.
