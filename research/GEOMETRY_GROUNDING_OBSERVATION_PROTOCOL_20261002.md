# Frozen localized-observation diagnostic

Continuation after the failed semantic-demixing screen. This is not yet a selected successor or a claim that Astra endorsed GroundingDINO. The missing requirement is useful, position-specific class evidence; further reconstruction is conditional on that source being useful.

Public source: `IDEA-Research/grounding-dino-tiny`, pinned revision `a2bb814dd30d776dcf7e30523b00659f4f141c71`, Apache-2.0. Standard installed Transformers only, safetensors, no remote executable code. Weights and images run locally on the authorized A800. No images, vocabularies or labels are sent to the checkpoint host. This introduces additional pretrained detection supervision and must not be called a matched single-encoder comparison or our original contribution.

Use the existing fixed96-image screen: UDD5 full40; seven other datasets eight images each, corrected IRRG Vaihingen. LandCover.ai replaces unlabeled iSAID. Physical GPUs4-7 only. Two original512 windows per image are chosen at one-third and two-thirds of the original sliding-window sequence, without masks. Singleton-window images are observed once. All eight domains are development data. This is a window diagnostic, not full-image dataset mIoU.

All20 alias strings per class are retained. Captions are lowercased as required by the official processor and packed round-robin by class, maximum192 tokens including special tokens, under the256-token model limit. Exact offset-based phrase masks exclude separators and special tokens. Every alias must be present exactly once; truncation or changed token IDs fails. The detector uses its native image processor, including its resize; that additional observation cost is explicit.

Primary source measurement: arithmetic mean of sigmoid token logits in each complete alias phrase. Native token maximum is an audit-only control; neither will be chosen retrospectively from masks. The confidence cutoff0.25 is the installed processor default, not label-fitted. Per-class evidence is the maximum of detected alias confidence times box/patch fractional overlap. Geometry fallback applies where no box supplies evidence. Missing detection never certifies absence. A box is not a semantic mask.

Raw900-query boxes and alias responses, unchanged Geometry patch scores and relation matrices are saved before any target mask is loaded. Only after all observations in a dataset are saved does a separate audit load masks. It measures class precision/recall, window IoU and exact Geometry/proposal/truth transitions. Raw rasterization controls are diagnostic predictions, not a claimed coupled model. Inspect vehicle/car false activation and water/low-vegetation coverage together, not only reduced car area.

Prospective source gate: on every domain/protocol, the fixed BoxMean observation must correct more already-wrong Geometry pixels than it corrupts already-correct pixels, including positive net corrections on the actual disagreements. All protocols must pass before another Geometry-constrained reconstruction is implemented/promoted. No dataset routing, alias selection or confidence threshold change based on masks. This source gate is necessary but not proof of a useful coupling, novelty, full-dataset mIoU or official-VIP superiority.

If observations fail, preserve the complete audit and reject this source under this rule. Do not spend a full20,092-image run on an unsupported observer. If they pass, a prospective same-source Geometry-coupling protocol, simple raster/fusion controls and support-shuffle/removal controls are still required before a full rollout.
