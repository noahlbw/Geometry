# 局部词源权重：Potsdam / VOC20全量迁移对照

已完成两个域共1,953张图的完整对照，全部唯一覆盖、同评测像素、同词/模板/视觉配置；补充组的无新增权重输出逐图精确重放前三组。没有测试打乱权重。

仅局部权重：Potsdam +0.2011pp，paired95% CI [0.1712,0.2337]；VOC20 −0.1071pp，CI [−0.2381,0.0322]。因此局部处理在Potsdam有小幅收益，VOC20没有明确增益。两分支都做词族处理时，Potsdam +1.3314pp、VOC20 −0.9708pp；当前不能作为已经成立的跨域统一终版。

VOC20主要风险来自宽视野词族/类别计数处理：chair IoU在无权重、仅宽视野、两分支、仅局部四组分别为64.6500/45.8747/46.9644/64.9066。该类G=1，许多其他类G=4，FamilySUM带来相对log(1/4)的分数偏移；词源数量不应自动被当成类别存在先验。保留原宽视野后，大幅chair下降消失，但局部词源规则整体仍无净提升。

直接回答“局部按词源分配、宽视野保留原20词是否可行”：计算预算可行、机制可解释，当前性能证据仅支持Potsdam小幅改善，不能支持普遍提升。建议优先保留原宽视野类别质量，再考虑局部重复表达的质量分配；现规则不能被写成已经识别好词/坏词或A/B竞争条件化可靠性。

绝对mIoU使用冻结VDD/ADE分支配置直接迁移，不是历史Potsdam/VOC最佳调参配置。VOC20忽略背景像素，不代表VOC21结果。补充的仅局部组是在看到VOC20损失后增加的固定规则消融，所有词/阈值/权重公式/参数均未重新搜索。

Frozen local p=1/(G*|E_g|): existing documented root only for generated families, all members for original lexical groups. Wide keeps all20, inheriting salience and e, with FamilySUM=LSE(tau*e-log(m_g))/tau. Coupling remains Lprime+gH(W-Lprime).

Three paired arms only: no new family/role weights, wide-family-only, full local-role+wide-family. No shuffled weights. Both uniform and weighted local scores use the same vectorized engine.

Direct fixed-profile transfer VDD->Potsdam and ADE->VOC20. No new label/word/parameter search. Both datasets were used in historical development, so this is exploratory transfer, not untouched validation.

计时：每域固定首/中/末三张完整图，预热后五次轮换顺序，CUDA同步，独占GPU核验。包含缩放、两个视觉分支、词归约、耦合写回、原尺寸恢复和CPU预测输出；不含图像解码及模型/文本初始化。不是全量平均延迟。内存为共同驻留模型/文本缓存峰值，不是独立部署内存。

两个版本使用同一个向量化局部引擎；为保持原浮点舍入，无权重类仍执行逐类uniform回退归约，词源非均匀类跳过该回退。几毫秒的速度差含该执行差别和测量波动，不能解释为词族语义规则带来的加速。

复杂度：新增静态词源先验O(CK)；已有局部词响应O(PCKD)，词归约O(PCK)，每类K=20。无额外视觉编码、细视野或alias×竞争类平方级张量。Geometry的P²关系开销未改变。即使某些局部权重为0，冻结实现仍计算20个词的点积。

以单局部窗P=1024计算，Potsdam的[patch,class,20] FP32张量约0.469MiB，VOC20约1.563MiB，ADE150约11.719MiB；只是一个中间张量的理论大小，不是整模型峰值。先验本身分别480B、1600B、12000B；log先验/索引和临时量另计。

解释：原始词表按保守词族均衡局部证据；有生成记录时仅已有裸词根具有局部权重，生成包装词局部权重为0、宽视野仍全部参与。宽视野也做FamilySUM词族处理，并非20词等权；继承的图像salience继续有效。FamilySUM还包含log(G/20)/tau类别偏移，完整模型对无权重的差值不能全部归因于局部。局部增量应看完整−仅宽视野。

Potsdam没有包装词生成记录：全部120个原词仍有正局部权重；每类词族数为20/18/20/19/17/20，clutter不合并。VOC20有精确生成记录：400个输入词中70个已有裸词根有正局部权重，330个包装词局部权重为0，宽视野仍读取400个。两者采取相同的来源规则，但输入来源不同，处理强度不同。VOC20忽略背景像素，不是VOC21背景协议。

局部归约是Lprime=0.07*log(sum_a p_a*exp(x_a/0.07))/T。p_a固定，但实际贡献比例随像素响应变化为p_a*exp(x_a/0.07)/sum_b p_b*exp(x_b/0.07)。这不能称为A/B竞争条件化可靠性：公式没有竞争类，也无法识别错误裸词根。

耦合写回Z=Lprime+gH(W-Lprime)。固定W时局部改动产生DeltaZ=(I-gH)DeltaL；固定L时宽视野改动产生DeltaZ=gH DeltaW。前者改变局部锚点，后者沿Geometry支持关系写回。边界/小目标是否因此受益仍须看类别和误差证据，不能由公式直接保证。

这是静态词源/重复证据处理，不是逐像素A/B竞争可靠性，也不保证错误语义会被识别。词族与加权LME本身不是全新算子。此前ADE局部规则未胜过词身份打乱对照；本次按用户要求不重做打乱对照，跨域收益也不能抹去该归因限制。
