# Alias处理的科学定案与主张边界

结论针对已测试的估计器和模型，不是关于所有可能筛词算法的不可行性定理。全量15入口、完整成本及配对统计已完成；按冻结判据选择全局Uniform，关闭额外普通局部软权重。最终架构/结果见 `CVPR_FINAL_MODEL_20261009.md`，可执行清单见 `alias_finalization_20261009/final_model.json`。

## 1. 保守软权重实际做了什么

实现依据：`DINOtool/dinotool/packed_alias_readout.py`的`PackedAliasReadout.coverage`。先用全部alias生成各类未加权LME分数；对每个位置/类别，从原分数选一个竞争类；比较alias与本类、竞争类的文本质心相似度，经sigmoid生成类内归一化q，最后使用

\[
w_{pca}=\frac{0.5}{K_c}+0.5q_{pca},\quad\sum_aq_{pca}=1,
\qquad S'_{pc}=T\log\sum_a w_{pca}\exp(s_{pca}/T),\quad T=0.07.
\]

它是竞争条件化的局部重分配，不永久删除任何词，也不在这一步改变宽视野的alias贡献。自然普通前景在本轮Retained/Uniform两版中本来均关闭此额外权重；PC60的额外残余概念protected处理另行保留。

相对原均匀LME，原始局部聚合的分数差满足

\[
-T\log2\le S'_{pc}-S_{pc}\le T\log\frac{K_c+1}{2}.
\]

K=20时，上界约+0.1646、下界约−0.0485；最终局部分数还要除以profile的temperature。这个界限制的是局部分数，不保证正确类别仍胜出，也不保证完整写回后的召回、FP或mIoU。保留半数均匀质量并不等于逐词只做小幅单向抑制：类内归一化会提高其他表达的权重。

## 2. 为什么尚不能称语义可靠性估计器

| 现有信息/操作 | 实际局限 |
| --- | --- |
| 全alias平均得到类原型 | 错误归属本身会污染原型；它不是独立语义真值 |
| 本类−竞争类文本相似度 | 衡量文本空间的相对区分，不判断当前区域的真实标签 |
| 原类分数选竞争者 | 依赖待纠正模型；真正类别未进入候选时，规则不一定能修复它 |
| 邻域或跨支持一致 | 同一个模型可以在整个区域一致地错；一致性不能自动认证正确 |
| 类内权重重归一化 | 降低部分表达同时增加其他表达，收益可能含尺度/类别校准作用 |
| 仅改变局部一条通路 | 宽视野的错误表达仍可能经原salience与聚合进入W；不能说完整系统已经拒绝它 |
| Geometry支持写回 | 约束空间关系，不认证语义。H可含负元素，最终影响不是单调抑制 |

这些局限与当前误差一致：一部分域需要减小误激活，另一部分正确局部覆盖却被修正丢失。需要的是能区分两种后果的证据，而不是仅让权重更不均匀。

## 3. 已有实验各自证明到哪里

| 证据 | 可以支持 | 不可以支持 |
| --- | --- | --- |
| 原高分辨率RivalFineHard同源八域平均+1.4129pp | 额外细视野条件下该准入规则有实用收益 | 把该收益/机制直接归给零fine的轻量模型 |
| FamilySUM在ADE约+1.98pp，但类别偏移对照相当或略高 | 类别质量/校准有影响 | 词级可靠性已经得到独立证实 |
| 跨支持删词价值相关0.00416、在置换区间内 | 当前估计器未预测出有用删除动作 | 所有可能条件处理都不可能 |
| 最新四域语义约束近零提升 | 该低成本候选不足以成为主贡献 | 仅凭低开销就晋升为终版语义模块 |
| 保守普通软权重在VDD/Potsdam的小幅收益 | 经验重分配可有小收益，不能说完全无用 | 跨域识别了“坏词”，或提供了主要性能改进 |
| 自然Retained=Uniform | 普通前景开关未影响本来关闭权重的实现 | 降权在自然图像上验证成功 |
| 删5词后下降、保留20更好 | 这一删除动作和聚合变化有害 |20个词全部都有正贡献，或扩词越多越好 |

硬删除还会改变类内归一化、宽视野salience与词数相关项，类别竞争又通过argmax和H影响其他类。仅比较“15词/20词”绝对成绩，不能把差值直接解释成五个词的独立语义价值。

## 4. 对最终模型的决定

全量定案：主四域Uniform−Retained为−0.042173pp，条件95%配对区间[−0.053431,−0.031829]；八遥感为−0.039106pp。最差迁移入口OEM−0.1497pp，通过既定实际简化门槛。权重有小幅正收益，不能说完全无用；保留其代码、配置和完整结果，但主终版统一移除，不按域拼接。自然两臂相同，不能算权重跨域成功。

保留同词、同观测、同参数的Retained/Uniform全量取舍。若满足冻结的实际非劣门槛，全局移除额外普通局部软权重；否则全局保留旧经验规则。不因某个域更好切换配置，也不把自然开关为零写成泛化成功。LoveDA D作为主入口，P独立读出单列。

无论最终哪个policy，撤回当前“能够识别局部竞争中有害alias”的核心贡献。保留已有LME和图像salience，它们让实际贡献依赖响应，但明确不提供语义正确性保证。PC60残余概念的额外信息预算和竞争规则单列，不冒称所有词处理均已删除。

词表可变数量已被实现支持；这属于输入接口。没有冻结的污染/重复/正确新词测试，不能宣称词表稳健性。生成候选或清理明确格式重复可作为透明输入流程，但不能把Qwen置信度或人工词表搜索包装为新的视觉可靠性估计。

## 5. 计算与论文定位

实际额外动态重分配是O(PCK)，从已计算类分数选竞争者并gather对应文本相似度；不构造位置×类×alias×全部竞争类张量。静态alias×类别文本相似度缓存仍为O(C²K)存储/相应点积预计算，需要如实区分。Geometry的P²关系与求解也仍存在；固定最多4+4视野提供有界整图预算，并非线性attention。

移除普通软权重不保证整图计时可分辨地下降；VDD现有独立进程Uniform反而稍慢，说明这些计时不能被用来宣称确定提速。计时以完整模型的实际结果为准。

最有依据的论文主线目前是视觉关系如何组织局部读取、并限制跨视野修正写回。宽视野VIP观测、LME、salience和经典二次解明确归属。额外筛词可以作为失败/边界分析，而不是为了三个框完整而强行成为新贡献。
