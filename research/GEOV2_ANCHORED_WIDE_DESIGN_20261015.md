# Geov2：以空间归属为锚的宽视野设计提案

日期：2026-10-15。状态：设计提案，尚未实现或评测；本文没有新模型的 mIoU、时延或显存实测。已有部署默认值不变。

建议研究的单一候选是：**固定 24 槽全图语义头 + 空间归属约束的残差槽读取 + 原 DonorBefore + 原固定结构写回**。不新增视觉编码器、训练参数、置信度 gate、数据集专属结构或槽数。

## 1. 为什么选择这一方向

依据 [七数据集全量消融](geov2_multidataset_ablation_20261015/REPORT_ZH.md)：

| 固定参考 g0 下的比较 | 已有结果 | 设计含义 |
| --- | --- | --- |
| QuerySlot24 − NoQueryRouting | 七域平均 −0.0836pp，95% 区间 [−0.2354,+0.0532] | 现有内容路由没有跨域平均收益的充分证据 |
| QuerySlot24 − NoQueryRouting，VOC21 | +0.7760pp，[+0.3787,+1.2050] | 不能据此删除所有局部 query；自然图像确有收益 |
| 同一比较，Potsdam / Vaihingen | −0.4090 / −0.3631pp，区间均低于零 | 新设计必须同时检查遥感退化 |
| Full − Raw32CoordinateGrid | 平均 −0.1513pp，Raw32 点估计在 6/7 域更好 | 坐标读出是强基线；但容量、插值与计分顺序混杂 |
| Full − 最佳普通加权融合 | 平均 +0.1533pp，[+0.0984,+0.2155] | 结构写回有收益，但不能夸大为巨大优势 |

上述区间条件于已选配置；历史 alias、校准和验证集查看带来的开发偏差仍然存在。它们支持一个研究方向，不证明下面的机制解释或新方案有效。

需要检验的机制假设：纯 raw 相似度可能把局部位置送往外观相近、语义不同的全图槽；原来的绝对混合还会在两视野已相符时再次注入槽平均值。当前数字不能单独区分这些原因。

## 2. 输入、固定部件与记号

- 共享同一冻结 DINO.text 视觉 backbone 的参数存储；全图和局部窗口分别前向。参数共享不等于只做一次视觉前向。
- 局部 DonorBefore、512 窗口、局部特征、关系 A、类别计分、背景处理保持不变。
- 一张低分辨率全图前向，产生 raw patch 特征 X，patch 数为 Nw。
- K=24，槽温度 0.1，球面聚类迭代 5 次，center=False。所有数据集相同。
- 不在这一轮同时修改全图分辨率：沿用冻结配置中的 long448 或 natural_short336_cap672，成对对照保持一致，并明确这仍是两种已有预处理协议。以后如主张单一预处理，再单独评测统一预算，不能沿用当前精度数字。
- 初轮冻结 alias、模板、局部/宽视野计分和背景校准。唯一允许逐数据集选择的新轮标量仍为 g0。

## 3. 全图语义记忆：复用已有实现

把 raw 特征单位化并确定性聚类，得到行和为 1 的软归属矩阵 P∈R^(Nw×K)。令 m=P^T 1，D=diag(m)。冻结语义头每个块的 Value 读取为：

    U = D^(-1) P^T V
    V_read = P U

隐式 patch 关系是 P D^(-1) P^T；只计算上述两个矩阵乘法，不构造 Nw×Nw 矩阵。保留已有冻结投影、残差和 MLP，得到语义网格 Y。

这部分对应现有 context_memory_observer.py，属于已有槽聚合实现，不能作为本次新提出的模块。

再按同一 P 生成单位化 raw keys c_k 和单位化 semantic values v_k，与现有 slot_prototypes 一致。缓存 Y、P、单位化 raw 网格 X 和这两个槽表。

K=24 表示全图的 24 个特征聚类槽，不是 24 个类别、24 个固定空间块，也不是 24×24 网格。同一槽可以覆盖多个不相连区域。

## 4. 新读取：先确定空间归属，再更新归属

对局部 patch i，令 S_i 表示其在全图网格上的双线性采样权重。P、X、Y 使用同一 resize/padding 坐标映射；边界与有效区域处理须和匹配对照一致。

读取三个坐标基线：

    pi_i = S_i P                 # K 维空间归属先验，重新归一化到和为 1
    qbar_i = normalize(S_i X)    # 同位置的宽视野 raw 描述符
    f0_i = S_i Y                 # 原坐标语义特征，暂不新增归一化

局部 raw token 单位化后为 q_i。使用相对证据而非绝对相似度：

    e_ik = ((q_i - qbar_i)^T c_k) / tau,    tau=0.1
    r_i = softmax(log(pi_i) + e_i)

实现时仅为数值稳定对 pi 加下界并重新归一化。该下界不是可调 gate 阈值。

r_i 是以下目标的唯一最优解（pi 正值时）：

    min over r in simplex: KL(r || pi_i) - <r, e_i>

含义：允许局部细节调整该位置的槽归属，但偏离原空间归属需要付出 KL 代价。e 是视觉描述符的相对相似度，不应称为已校准的语义似然或正确率。

这使用整张软归属图 P 的空间支撑，而不是到单个槽质心的欧氏距离；槽的形状和多片分布因而仍能影响读取。

## 5. 只注入相对坐标基线的语义残差

候选宽视野特征定义为：

    delta_f_i = beta * (r_i - pi_i) Vslot,    beta=0.5
    fwide_i = normalize(f0_i + delta_f_i)
    W_i = inherited_class_scorer(fwide_i)

关键是减掉同一位置已有的槽混合 pi_i Vslot。它保留 f0_i 中无法由 24 个槽精确重建的细节，仅修改槽归属改变所带来的语义增量。

beta 固定 0.5，继承当前默认，不逐域调参。新方案没有增加可调标量数量；是否可以进一步删掉 beta，是后续一次独立简化问题，不在首轮同时搜索。

可严格陈述的性质：

1. 当 q_i=qbar_i 时，e_i=0、r_i=pi_i，候选恰好退化为 normalize(f0_i)，不存在额外槽注入。
2. beta=0 时恢复匹配的 NoQueryRouting。
3. sum_k(r_ik-pi_ik)=0。给所有槽 value 加相同向量，不改变该残差项；所有 value 相同时残差为零。
4. 若各 v_k 范数不超过 1，归一化前 ||delta_f_i||_2 ≤ beta ||r_i-pi_i||_1 ≤ 2 beta。该界不保证归一化后变化很小，也不保证类别正确。

不能声称的性质：softmax 先验不是硬掩码，足够大的 e 仍能越过低先验；本方案不保证不跨物体、不污染边界或 mIoU 必然提高。低分辨率 P 漏掉小物体时，也可能把错误空间归属固定得过强。

与旧代码区别：

- 当前 QuerySlot：softmax(q C^T / tau)，再将 f0 和路由 value 绝对混合。
- 已有 spatial_weight：对槽质心距离加惩罚，没有读取 P 的完整空间支撑。
- 已有 global_residual / coordinate_residual：按槽减去全局均值或槽质心处特征；新方案减的是每个输出位置自己的 pi_i Vslot，并以 q_i-qbar_i 更新归属。
- 以上区别仅说明计算不同，不自动成立为论文创新性结论。

## 6. 与局部分支的最终耦合

L 是原 DonorBefore 的局部类别分数。保持同一固定结构写回：

    Z* = argmin_Z  0.5 ||Z-L||_F^2 + 0.5 ||A(Z-W)||_F^2
    H = (I + A^T A)^(-1) A^T A
    Z* = L + H(W-L)
    Z = L + g0 (Z*-L)

两处耦合分别是：局部 raw query 调整宽视野的读取；局部关系 A 控制最终语义差分的写回。全图槽归属 P 和局部关系 A 是不同矩阵，不能写成同一个 A 同时完成所有读取和写回。

H 保留 A 零空间内的局部分量，其他模态的作用由 A 的奇异值决定；这不等于严格保证全部物体边界或局部细节不变。g0>1 是超松弛，但也可能越过 Z*，没有精度或稳定性保证。首轮与现有消融一致，仅扫描 {0.25,0.5,0.75,1}。

## 7. 复杂度与执行方案

新读取没有额外 RGB 前向、SAM、第二 backbone 或局部×全局 patch 注意力矩阵。每个窗口额外保留 Nlocal×K 归属，路由工作量为 O(Nlocal K (d_raw+d_sem))；e 可用 (q-qbar)C^T 一次矩阵乘法，语义差分用 (r-pi)V 一次矩阵乘法。

相对旧 QuerySlot，主要新增的是 raw 网格与归属图缓存，以及每窗两次坐标采样。缓存增加约 Nw(d_raw+K) 个元素。例如 Nw=1024、d_raw=1024、FP32 时约 4.1 MiB；这只是缓存估计，不是端到端峰值增量，实际还有临时量与 allocator 影响。

全图语义头的槽读取避免该 head 的稠密 patch 关系；不能据此声称整个 ViT 编码器复杂度线性，冻结 backbone 自身仍有注意力计算。

首轮保持 shared_canvas 的精度路径，隔离新读取的效果。不要同时换 direct patch 计分、槽数、分辨率、精度和求解器。已有 optimized48 在 VDD 的成本回归说明不能仅凭理论 FLOPs 宣称更快。

通过后再做执行优化：复用已有 GPU gather/scatter 槽构建、逐窗口释放临时量；结构写回可考虑求解 C 个右端而不显式形成 H，但需要分别验证数值等价和实测成本。dense A 的存储与分解不会仅因不存 H 而消失。

首轮工程验收目标：相对同精度、同 K 的旧 QuerySlot，端到端中位时延增加不超过 5%，peak allocated 增加不超过 50 MiB。它们是预设目标而非预测；若必须显著加预算才改善，不作为快速主模型。

成本需独立进程、同一 GPU、同一 CPU 线程、固定图集、同步计时和预热；记录 allocated/reserved、初始化峰值，端到端边界沿用 CPU RGB tensor 到原尺寸 CPU 标签。小于几毫秒的差异要看跨进程重复波动。

## 8. 必须回答的实验问题

所有下列读取对照使用 K=24、同语义头、同归一化/插值/计分顺序、同 alias、同局部 DonorBefore 与同写回。Raw32 另列为已有替代系统，不能当纯路由消融。

| 对照 | 定义 | 回答的问题 |
| --- | --- | --- |
| 坐标读取 | beta=0 | 新读取是否比不路由有净收益 |
| 旧 QuerySlot | 现有 raw softmax + 绝对混合 | 是否改善当前模型 |
| 完整候选 | 本文公式 | 主候选 |
| 无空间先验 | pi 换为均匀分布，其他相同 | 空间归属是否贡献收益 |
| 无相对证据 | e=q C^T/tau，其他相同 | 减去同位置宽视野参照是否必要 |
| 绝对语义混合 | normalize((1-beta)f0+beta rV) | 减去原有槽语义是否优于绝对混合 |
| 打乱局部 query | 仅置乱 q，固定 qbar、pi、f0 | 对齐对应是否重要；不能单独证明净收益 |

额外的架构证据分开做：同 K 下冻结原生 head vs 槽 head；同新 L/W 下局部端点、宽端点、等权融合、可独立调权的普通融合、结构写回、匹配观测预算的 LPOSS/其他传播。DiagonalH 不能代替 LPOSS。

开发域预先包括 Potsdam/Vaihingen（已有路由失败）、VOC21（已有收益）、ADE150（已有近中性）；其余 VDD、UDD5、OEM 与 COCO-Object81 用于冻结候选后的跨域复核。这些域多数已被历史开发查看，不能称为从未查看的独立测试。

首先在声明的开发 split/按航片或区域分组的 split 比较，冻结一个候选后全量报告，不根据新结果换主数据集。各方法同 g0 的配对结果和各自等预算选 g0 的结果都保留。另报全局 g0=0.5 的统一配置；逐域 g0 只作清楚标注的适配协议。

候选晋级至少要求：跨域平均优于匹配坐标基线和旧 QuerySlot；主要遥感退化得到缓解且不靠牺牲 VOC21；同一冻结模型满足成本目标。用分组配对区间衡量不确定性，不要求通过挑数据证明每一行都上涨。正式数值非劣界应在开跑前与误差条、应用目标一起写进 protocol，而不是看到结果后决定。

论文机制图应量化：旧/新路由的错误类别槽读取质量、修复/破坏像素变化、按物体尺寸与边界距离分桶的收益，以及 pi→r 的变化。槽并非类别，类别污染可用 GT 对槽支撑做离线统计来定义；GT 只用于分析，不能进入推理。用固定规则同时抽取成功和失败样例。

## 9. 论文叙事与边界

建议问题表述：在高分辨率开放词表分割中，全图语义需要由局部细节修正，但不受空间约束的跨尺度内容读取可能破坏已建立的对应关系。因此先以全图空间归属为锚调整读取，再通过局部结构写回语义差分。

可以验证的贡献是一个受空间归属约束、跨视野一致时恒等的残差读取，与已有结构写回共同组成零训练推理系统。聚类、KL 正则、softmax、低秩池化和二次闭式解本身都不宜宣称首次提出。是否具有足够的文献差异，还要专门核查相关跨尺度注意力、引导上采样、残差注意力与区域传播工作；本文没有完成这一文献审查，也不承诺 CVPR 接收。

Alias 是固定语言接口，不进入新路由。架构证据优先在同词表、同模板和匹配背景校准下比较；历史经标签开发的精选 alias 单独披露来源。推理不读取标签与开发中未使用标签是两件不同的事。已有 CanonicalForeground 收益不能独立证明 Kev 筛词有效。

新方案如果只达到与坐标读出持平，主模型应保留更简单的坐标读取，把 QuerySlot 的域依赖性写成分析结果，不能为保住模块名称继续添加 gate 或挑选数据集。

## 10. 实现位置与最小交付

- query_slot_memory.py：添加独立的锚定读取函数，显式接收 pi、qbar、f0；不改变旧函数默认行为。
- 全图 memory 构建：可选保留 raw/P 两个网格，并共享原 semantic/key/value。
- 观察器按窗调用新函数；沿用 shared_canvas 和原 scorer/writer。
- 单元验证只覆盖关键代数/集成性质：q=qbar 的基线恒等、beta=0 的基线恒等、公共 value 平移不变、padding 后坐标一致，以及与旧局部 DonorBefore 的逐窗等价。
- 单独冻结实验协议、原始统计与成本脚本。未完成上述评测前，不替换发布默认模型，不把本提案称为最终最佳配置。
