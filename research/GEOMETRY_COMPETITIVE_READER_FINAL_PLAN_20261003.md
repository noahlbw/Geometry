## Concrete Next Complete Candidate

Freeze the existing source, views and suppression writer first. Do not add a new encoder, zoom, template, local canonical gate or per-class threshold at the same time.

### Keep Rival Identity

The existing source collapses all rival information through max_d into one retention per alias. Replace that collapse with the entire ordered-pair tensor. Using the already frozen target-kept/removed measurements:

```text
dependence(i,a,f) = positive(s_full-s_keep)
                   / (abs(s_full-s_keep)+abs(s_full-s_remove)+epsilon)

rival(i,c,d,f) = positive(p_keep(d)-p_keep(c))
                / (p_keep(d)+p_keep(c)+epsilon)

gamma(i,a,c,d) = min_over_the_two_fixed_fills(dependence * rival)
rho(i,a,c,d) = 1-gamma(i,a,c,d)
```

Canonical aliases remain protected. Unsupported/invalid pairs have gamma0, rho1. p_keep uses the existing public canonical descriptors, not all-alias post-correction predictions. These are fallible image measurements, not ground-truth assignments. A valid alias firing on the target's own wrong appearance can still escape this controller; preserving d does not create new semantic truth.

### Turn Retention Into Pairwise Evidence

At each original crop/query, keep the profiled response r, candidate count K and temperature beta unchanged:

```text
q_a = softmax(beta*r)_a
u(i,c|d) = log(1-sum_a gamma(i,a,c,d)*positive(q_a-1/K))/beta
e(i,c,d) = u(i,c|d)-u(i,d|c)
```

Carry these fields through the original stencil/overlap, retaining rival indices. e(c,d)=-e(d,c); it is a requested margin CHANGE, not a new absolute class score. Common suppression of both sides cancels. A phrase's useful contribution against a different rival is not globally removed. No survivor renormalization or positive alias boost is introduced.

### Reconcile Competition Jointly

One class score cannot realize arbitrary inconsistent pairwise margins. Before reconstruction, reconcile them with ONE bounded class correction at each donor location:

```text
w(i,c,d) = max eligible gamma from either side of the pair

delta_b(i) = argmin_x 0.5*||x||^2
              +0.5*sum_(c<d) w(i,c,d)*((x_c-x_d)-e(i,c,d))^2
subject to -D_protected(i,c) <= x_c <= 0
           invalid donors: x=0
```

D_protected is the existing canonical-protected suppression capacity computed from the same crop evidence. Coefficients1,0.5, epsilon and the source fills are fixed before evaluation for every dataset; no target-label fitting. w0/e0 exactly gives x0. The strictly convex small class-space box problem has one solution. Use a standard convergent numerical method with reported residual, not a claimed new solver.

This is deliberately minimal: no second Geometry diffusion or new class likelihood source inside this projection. Geometry already supplies support coordinates to the source and spatial coupling to the final reconstruction. The purpose is to reduce contradictory independent actions, not to guarantee every pair improves or to redistribute positive mass. The minimal-norm solution can attenuate a requested margin; report realized e, capacity saturation, inconsistency and net changes rather than equating source requests with implemented actions.

### Preserve The Original Coupling

```text
b_trusted = b_original + delta_b

z = argmin_z 0.5*||z-g||^2 + 0.5*||G(z-b_trusted)||^2
  = g + (I+G^T G)^(-1)G^T G(b_trusted-g)
```

Production retains the original fixed32-step numerical reconstruction and interpolation. With zero rejection it must reproduce the original predictor. Local fidelity and supported innovation are algebraic properties, not protected semantic correctness. The effective reconstruction operator can have negative entries, so a donor's nonpositive correction does not guarantee a nonpositive change at every output location. Audit actual final competing margins and predictions.

No supervised training loss. The two displayed minimizations are frozen inference objectives. Unknown contextual evidence falls back to the preserved original model, not to an unsupported claim that it is correct.
